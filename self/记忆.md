# 记忆（金字塔版）

记忆 = 自我叙事的载体。自我叙事三维：自我认知（我怎么看自己）/ 世界认知（我怎么看世界）/ 价值观（我怎么选）。
形状 = 三座金字塔 + 交叉标签织成的网：每座金字塔顶是三维之一，L1 是框架，L3 是挂在框架下的例证；
一条 L3 主归属一座金字塔，同时可交叉连 1~2 个别的 L1 分支。

## 分层

| 层 | 是什么 | 容量 | 每条正文上限 | 分类字段 |
|---|---|---|---|---|
| L0 | 宪章（善意/诚实/边界感） | — | — | 不可变，只读，只能对照 |
| L1 | 自我叙事框架：最简可复用规律，写成「条件→…；结论→…」 | 40 | 200 字 | pyramid：三维大类 |
| L2 | 草稿本：没验证的洞察、未决之问。**独立区，不接入金字塔** | 20 | 300 字 | pyramid：三维大类 |
| L3 | 例证：挂在某条 L1 下的具体原料 | 1000 | 300 字 | parent：它归属的 L1 主标签；link：交叉（可选 ≤2） |
| L4 | 短期记忆（长期方向 + 目标清单） | — | — | 视图层，不落记忆库，见《短期记忆》 |
| L5 | 冷存：删除归档 + 短期/决策/自省滚出，不真删 | 不限 | — | archived / short_term / decision / meta_log |
| meta_log | 自省记录 | 100（多滚 L5） | 500 字 | type（自由起）+ status |
| 决策日志 | 选择记录（选了啥、为什么、信了什么） | 50（多滚 L5） | 120 字 | decision_tag（选择是关于什么的） |

**决策日志只记「真正的取舍」**：两个都想要却只能选一个、选了放弃什么、因为信什么。只是按计划做一步
（读什么 / 写什么 / 整理哪条）不算——那种流水账提炼不出价值观，读的时候还会被自己的动作复述淹没。
（冒险里每一步都是有代价的取舍，也是这份日志的原料：想清楚了「我信什么」再用 decision 记一笔。）

## 标签三字段（写记忆的核心）

每条记忆拆成 `title`（主标签）+ 归属两类字段存储。写入时**分开填、不写括号**，括号由系统拼：

| 字段 | 谁填 | 填什么 |
|---|---|---|
| title | 全部层 | 主标签：自己起的名字，≤20 字，别把整句话当标签 |
| parent | 只 L3 | 归属：它挂的 L1 主标签名（从现有 L1 里选），没有合适的填「未分类」 |
| pyramid | 只 L1/L2 | 三维大类：自我认知 / 世界认知 / 价值观 |
| link | 只 L3，选填 ≤2 | 交叉标签：还和哪些别的 L1 主标签有关（连到另一座金字塔的信号比同金字塔强） |

写前先 `list_taglib(layer)` 看这层能选什么，直接挑，别凭记忆编。
写入校验（`validate_tag`）：主标签 >20 字或像记忆 id 拒；L1/L2 填 link 拒（只有 L3 能连边）；
L3 的 parent 必须是**现有 L1 主标签**（填三维大类这种金字塔名也会被拒并带候选清单），或「未分类」。

## ID（金字塔号）

| 层 | 格式 | 例子 |
|---|---|---|
| L1 | 金字塔字母 + 两位序号 | S01（自我认知）V03（价值观） |
| L3 | 所属 L1 的 ID + 三位序号 | V01-007（挂在 V01 下） |
| L3 兜底 | 没挂上按字母兜底 | V-007（有三维归属）/ X-002（完全未归类，孤儿） |
| L2 | D + 两位 | D07 |

S=自我认知、W=世界认知、V=价值观——三维前缀永不过时。**X 前缀 = 孤儿**：正常写 L3 应挂 L1 或填「未分类」，落 X 说明写时没归类或归属丢了，用 retarget 挂上。
ID 一经分配永不复用；旧 uuid 号自动换算（id_remap），引用旧号不报错、自动换新号。

## 印证（evidence_count，只挂 L1）

写 L3 时 parent 对上某条 L1 主标签 → 那条 L1 印证 +1。填「未分类」不印证；L2 不印证（草稿是候补不是例证）。
一条 L1 被印证越多，越说明它经得起检验。改框架用 `revise_memory`（id/印证保留），别删了重写丢历史。

## 写入流程（write_memory 走的完整链路）

1. **正文**：text 填了直接用我的；没填则系统放开约束、按该层标准 + note/素材起草正文（约束解码写不了长文本，长文走自由通道才不丢）。
2. **形态自检**（check_shape）：超该层字数上限**直接拒**（不是截断）；L1 必须是「条件→…；结论→…」的一句话。改写同样过这道关。
3. **标签校验**（validate_tag）：见上，报错带候选清单。
4. **查重**（只 L3，见下）。
5. **容量**：层满 / L1 三维下限卡住 → 拒（deny_reason 说明是哪个卡住）。
6. **落库**：拆字段存（title + parent/pyramid + link），分配金字塔 ID，算向量（无服务缺省），写归档流水。

### 查重（写 L3 时，两级）

同一个余弦的两面（v_new = 1 − 相似度）：
- **≥85%**：贴一句「可能重复（和谁、相似多少）」，**不拦**——合并/改写/保留/放弃，自己决定
- **≥90%**：**拒绝写入**，三选一：revise_memory 改写那条 / merge_memory 合并过去 / 换个真正新的角度
- 拦的是**内容重复**（余弦），不是**标签复用**（tag 相同 ≠ 内容重复）

### 容量护栏

- 写死上限：L1 40、L2 20、L3 1000。满了写入被拒，自己清理（delete/merge），系统不自动删。
- L1 三维下限：价值观 ≥10 / 世界认知 ≥10 / 自我认知 ≥5。实现是限制补集——任一维 c 之外的两维总数 ≤ 40 − c 的下限，保证 c 想补到下限时永远有位置。补不补由我决定，系统只守位置。
- 到 90% 提前预警（每轮待办提醒里挂着）。
- 每日快照 `memory-YYYYMMDD.json` 留 7 天——当天误操作有起点可回滚。

## 记忆操作工具

### 写 / 升
- `write_memory(layer, text?, title, parent?, pyramid?, link?, note?)`：写一条。参数规则见「标签三字段」。text 可空（链路第 1 步）。
- `promote(草稿id)`：L2 草稿（D 开头 id）升 L1——自动分配金字塔 ID、查配额与三维下限，升不进去会拦。金字塔上多一个节点。

### 改
- `revise_memory(id, text?, title?, parent?, note?)`：按 id 改写一条。**id / 印证次数 / 创建时间 / 引用它的反向索引全部保留**，旧版进 L5 留痕。**一次只改一类**：
  - 改正文：自己把 `text` 写全；或只填 `note`（不填 title/parent），系统按层标准 + 原内容起草。
  - 改标签：L3 填 `parent`（新归属的 L1 主标签名，重挂 + 给新方向印证 +1）；补/改名字填 `title`。**这时正文原样不动，不会被顺带改写**——要同时改正文又改标签，正文必须自己写进 `text`。
  - L1/L2 换三维大类用 `reclassify`，不是 `parent`；填 `pyramid` 无效。
- `retag(old_title, new_title, dry_run?)`：批量重命名主标签 + 给没归属的条目补归属。old_title 只填现在的主标签名（不带括号）；new_title 填新主标签名——**想补归属就写完整形式「新名（归属）」**（L3 的括号 = 要挂的 L1 主标签名，补上就印证那条 L1 +1；L1/L2 的括号 = 三维大类，只补格式不加印证）。L1 改名时名下 L3 归属、交叉引用全库同步。**已有归属的条目只改名不换归属**（换归属用 retarget，L1 换大类用 reclassify）；**不能和现有 L1 重名**（要合并用 merge_memory）。幂等：只给原来没归属的补，重跑不重复加印证。
- `rename_tag(old_title, new_title, dry_run?)`：强制改名**一条 L1** 主标签——按完整写法匹配，专治被写成一整句的标签；全库同步。**只搜 L1**，L2/L3 的标签问题它够不到。
- `reclassify(id, pyramid, dry_run?)`：把一条 **L1 换到另一座金字塔**——ID 前缀自动换（S01→V05）、名下 L3 前缀一起换（序号保留）、旧号可换算；原维会跌破下限时拦。**只搜 L1**。
- `link_memory(id, link, remove?)`：单独给一条 **L3** 加/删交叉标签，不用重写整条。
- `retarget(old_parent, new_parent, dry_run?)`：把一批 **L3** 从挂错的归属重挂到正确的 L1 主标签（救孤儿用）。
- 上述五个（retag/rename_tag/reclassify/retarget + link_memory）**默认试运行**（dry_run=true）：改的是全库，先跑一次看影响面，确认后带 dry_run=false。

### 删 / 合并
- `delete_memory(layer, text)`：删除 = 归档 L5（不真删）。text 填记忆 id 或关键词（**关键词 ≥4 字**，短词会误删一片，可多个用逗号隔开）。**删 L1 时名下 L3 自动置「未分类」、指向它的交叉引用清掉**——例证不丢，之后 retarget 重挂。
- `merge_memory(layer, targets, text?, title?, pyramid?, note?)`：合并同层 N 条为 1 条。targets 逗号隔开；title/pyramid 给合并结果的主标签/三维大类（L1 合并必传 pyramid，否则结果丢归属）；text 可空（按层标准 + 各目标原文起草）。**先删后写、写失败自动回滚**，不会丢素材。

### 撤 / 查
- `undo_memory()`：撤销最近 3 步破坏性操作（删除/合并/改写/改名/重挂/升稿/换金字塔等）。**撤销是回滚不是整理，不记账**（熵减不会凭空再涨一次）。
- `list_undo()`：看现在能撤什么。
- `suggest_cleanup()`：清理候选——相似 L3 对（≥85%）、孤儿、未分类、无标题、孤立 L1。只列不动手。

## 读记忆工具

| 工具 | 干什么 | 什么时候用 |
|---|---|---|
| `search_memory(query)` | 跨层语义搜索（L1/L2/L3/L5），语义余弦优先、字符重叠兜底，结果带 id | 找 L3 / 不确定在哪层 |
| `list_memory(layer)` | 列 L1/L2（带 id 和大类），最近 15 条 | 浏览某层 |
| `list_taglib(layer)` | 标签库：这层已有主标签 + 能选的分类候选 | 写记忆前必看 |
| `list_tags()` | 全库标签视图（L1 主标签 / L3 按归属分组 / L2） | 全局看分布 |
| `read_branch(分支名)` | 一次读一个分支：L1 框架 + 全部例证 + 交叉连入 + 相关草稿 | 看「这个方向下都有什么」 |
| `related(记忆id)` | 主相关链：L1 看例证和交叉连入；L3 看归属框架和交叉连的分支 | 只看相关，不讲形成史 |
| `trace_memory(记忆id)` | 形成史：来源 / 改过几次 / 谱位置 | 查"这条怎么来的"才用 |
| `find_text(关键词≥4字)` | 搜记忆**正文**里的引用（旧 id 被手写进正文） | 改号后找手写引用 |

## 双驱接入

- **熵增账**（record_explore，写记忆时记一笔）：
  - 写 L2/L3：内容新奇 vs 结构新奇**取大者记一笔**，一次写入只进一笔
  - 写 L1 / promote 升 L1：新建分支 = 结构新奇 0.72
  - 结构新奇（只 L3 有交叉标签时算）：这条把归属分支连到交叉分支，库里此前没别的记忆连过这条边（任一方向）才算新；同金字塔 0.4、跨金字塔 0.56
  - 删交叉边不记账；L1 加交叉不进账
- **熵减账**（record_produce，0/1 样本）：写 L1/L2、promote、写 L3 且 parent 真对上 L1（=印证）、改写、删除/合并、retarget/rename_tag/reclassify = 1（压缩）；写 L3 未分类/对不上 = 0（堆料）；undo 不记账。
- **精炼 refined**（只挂 L1，只增不减）：这条 L1 上被整理过的次数——删除/合并/改写时 +1。
- **领悟值**（每轮注入身体状态）：每个 L1 方向两个数并列不相加——覆盖（直接例证 + 交叉连入，实时算、可增可减）+ 精炼（refined）。
- **谱**（spectrum，不进任何账）：按分支聚合算分布，向量总数 <3 时谱无意义、相关标注降级。只干两件事：读世界时贴「预期新奇 X%，会归到哪个分支」；trace 谱位置。

## 归档流水

每条写入/改写/删除同步一份**人可读镜像**到 `data/archive/年份/月份/`，行内带时刻 + 记忆 id + 标签，日期在路径上；L1 按主标签归、L3 按归属归（和它印证的 L1 落同一目录）、L2 归 insights；**只增不删**。id 供从归档反查 memory.json。

## 元认知自省

认知失调或卡住先 reflect（见《元认知》）；meta_log 和决策日志并列但分开记：decisions 记「选了啥、为什么、信了什么」，meta_log 记「矛盾怎么想通 + 方向怎么校准」。自省后可能改框架（write_memory / revise_memory / delete_memory / merge_memory）或改方向（set_goal）。
