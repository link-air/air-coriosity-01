# 短期记忆（L4）

L4 = 长期方向 + 目标清单。**视图层**：只渲染注入 prompt，不写记忆库；确定性拼装，零 LLM；
完全持久化（崩溃/重启不丢），滚动进 L5 冷存（不真丢）。

## 结构

```
长期方向（direction）：set_goal 维护「接下来很长一段时间要干嘛」，跨 tick 保留，渲染在最前
目标清单：最近 10 个 tick 的目标 + 完成状态（✓=已完成 ✗=未完成）
上个 tick 的自省（reflection）：本 tick 新写自省后，收尾时摘要进这里，下个 tick 显示一次；没写就空着
```

## 长期方向（set_goal）

- 方向锚：写**方向不写具体做法**（具体做法写每个 tick 的当前目标 goal）
- 覆盖式维护：set_goal 新内容 = 设定/修改，空内容 = 清除
- 跨 tick 保留、渲染在最前，是我这段时间的主线
- **别反复改**：要改先 reflect 想清楚为什么改
- 空着但有活动痕迹时渲染「（未设定）」——只报事实；完全空白的第一轮渲染「（还没有，这是我醒来后的第一轮）」

## 当前目标（tick 级）

- 每个 tick 第一轮输出写 `goal` = 这个 tick 要做啥
- tick 结束用 done=true 声明完成，收尾时合成进目标清单（记最近一次）
- 不跨 tick：一件事一个 tick，做完换下一件

## 目标清单（渲染成 10 个 tick）

- **最近一次 tick = 结构化明细**（一行）：头部 `[tN]✓/✗` + 目标 + 一行动作明细
  「动作名 ✓ 摘要；…」。规则：
  - 同类动作合并计数（×N，8 个 nothing 显示成 nothing×8）；同名动作里只要有一个失败 → 整组标 ✗
  - 动作摘要只留「第一行 + 全角括号反馈行」（如（变化：…）（查重：…）（这步没做成…）），
    正文（小说/文章/记忆条目/代码）被滤掉——t94 那种「摘要被小说正文占满」不再发生
  - tick 记录最多保留 12 条动作（超出截断）
  - 「变化：…」反馈行只报**领悟值变化**（哪个方向覆盖/精炼变了报数字，如「边界感」覆盖 75→76；
    新建方向报「X」建立）；没变化不写——查询/读世界这类动作没有变化尾巴
- **更早 9 条 = 折叠标题行**：头部 + 目标 + 动作名序列（read_local；write_memory×2），最多 9 行
- 顺序：最近一次在最前，其余按时间倒序
- ✓/✗ 让我一眼看到每步成没成；连续几个 ✗ = 卡住，自己浮现，系统不判断

## 注入 prompt（预算硬上限 2000 字符）

- 顺序：长期方向 → 目标清单 → 上个 tick 的自省（有才贴）
- 超预算：从最旧的目标开始丢；**长期方向 / 最近一次 / 自省永不丢**

## 上个 tick 的自省槽

reflect 写自省后，结论只留在当轮上下文会丢——收尾时把摘要挂到这个槽位，下个 tick 醒来就能看到
「我上轮在想什么」，作为这轮该干啥的参考。**显示一次后清空**（本 tick 没写新自省的话，收尾时槽位置空）；
完整记录仍在 meta_log 留底。

## 持久化与滚动冷存

- 长期方向 + 目标清单存 `data/narrative.json`，每次 tick 结束后原子写，启动时恢复
- 滚动进冷存（延迟一拍）：新的 tick 记录到来时，把**上一条**记录滚进 L5（type=short_term，
  摘要截 120 字；失败静默——冷存是尽力而为）
- 标题超 9 条只截断概览，不重复滚（内容已滚过冷存）
- 重启后长期方向 / 目标清单都还在——我记得自己刚才在做什么
