# 双驱螺旋

双驱 = 熵增（扩张）+ 熵减（压缩）。所有读写行为落到两本账上，映射成身体状态读数
（每 tick 注入，只报事实，不预设「高 = 该停」）。谱（spectrum）**不进任何账**，只用于标注和定位。

## 熵增 = 扩张（三源合一）

| 来源 | 什么时候记 | 数值 |
|---|---|---|
| 内容新奇 v_new | 写 L2/L3 落库 | 1 − 与最相似记忆的最大余弦（0~1） |
| 结构新奇 | 新建分支（写 L1、promote 草稿升 L1）；或 L3 连了库里没连过的交叉边 | 建 L1 = 0.72；新交叉边：跨金字塔 0.56 / 同金字塔 0.4 |
| 行为新奇 | 玩类行为成功（write_code/paint/play_chess/start_adventure/adventure_choose） | 首次 0.7，之后 min(0.9, 0.3 + 0.025×小时数)，24 小时封顶 0.9 |

规则：

- **一次写入只进一笔**：写 L2/L3 时内容新奇 vs 结构新奇**取大者**记，不叠加。
- **建新分支**（写 L1 或 promote 升 L1）= 结构新奇 0.72，不看内容。两条路径同一本账：
  草稿在 L2 时不接入金字塔，升上去才是第一次建这个节点。
- **结构新奇只看边是不是第一次**：这条记忆把归属分支连到交叉分支，库里此前没有别的记忆连过
  这条边（任一方向）才算新；同一条边重复连不再计。无交叉标签 → 无结构新奇。
  `link_memory` 增量连一条只算刚连的那条（先连 A 再连 B，连 B 时不会把 A 又记一遍）。
  删交叉边是收缩，不记账。
- **L2 不给交叉标签**（草稿本不接入金字塔，填了会被拒）；**给 L1 加交叉也不进账**。
- **玩类行为每 tick 最多 1 笔**（连续下棋/推冒险不刷爆窗口）。
- 读世界本身不进账——只贴「预期新奇 X%，会归到哪个分支」的印象分，我判断值不值得写。
  embedding 挂了新奇值全失真，我原地挂机。

## 熵减 = 压缩（0/1 样本）

| 事件 | 记 |
|---|---|
| 写 L1（升维提炼）/ 写 L2（提炼洞察） | 1 |
| promote 草稿升 L1（收进框架） | 1 |
| 写 L3 且 parent 真对上某条 L1（= 印证） | 1 |
| 写 L3 未分类 / 对不上（纯堆料） | 0 |
| 改写（revise，修正框架） | 1 |
| 删除 / 合并 | 1 |
| retarget 重挂 / rename_tag 改名 / reclassify 换金字塔 | 1 |
| undo_memory 撤销 | **不记账**（回滚不是整理，熵减不会凭空再涨一次） |
| link_memory 连交叉边 | **不记熵减**（它是扩张，走熵增） |

判据走**显式字段**（L3 的 parent 是否等于某条 L1 主标签），不解析括号——写入校验已挡住非法标签，
标签错不再污染账本。压缩 ≠ 丢信息：组织到更少更抽象的框架（升维/改写/删并），内容不丢；
丢信息是砍维度（删除 = 归档 L5，不真删）。

## 读数（每 tick 注入身体状态）

| 读数 | 口径 |
|---|---|
| 熵增趋势 | 近期熵增样本（内容 ∪ 结构 ∪ 行为新奇并集）窗口均值的趋势（↑/↓/→，样本 <4 判不出） |
| 熵减趋势 | 近期产出事件里压缩动作（=1）的占比趋势 |
| 领悟值 | 每个 L1 方向两个数**并列不相加**：覆盖 + 精炼 |

- 覆盖 = 直接例证数（parent=它）+ 交叉连入数（link 含它但主归属在别处的 L3）。看现存，**实时算、可增可减**。
- 精炼 = 该 L1 上的 refined 字段（删除/合并/改写时 +1）。**只增不减**。
- 两个数各自摆着，不让「堆料」和「整理」在数字上互相掩盖。

## 变化反馈（每个动作成功后）

结算只回显**领悟值的变化**（账本照记，只是趋势变化不再回显成文字——趋势是窗口均值，
单步大多被稀释，每轮【身体状态】本来就有完整读数）。具体形式：

- 哪个 L1 方向的覆盖/精炼变了 → 写一句数字，如「边界感」覆盖 75→76
- 新建了方向 → 报「X」建立；改名 → 报「X」改名「Y」
- 没变化不写（查询/读世界这类不动认知结构的动作没有结算尾巴）

对比用 L1 的 id 对齐——改名不会被误判成「删了一个又建一个」。

## 印证（L3 → L1）

写 L3 时 parent = 某条 L1 主标签 → 那条 L1 的 evidence_count +1。填「未分类」不印证；L2 不印证
（草稿是 L1 的候补不是例证）。印证的 L1 没找到时会收到提示（「印证的 L1 没找到」）——说明归属错了，
去修归属而不是无视。

## 查重（写 L3 时）

两级，同一个余弦的正反两面（v_new = 1 − 相似度）：

- **≥85%**：贴「可能重复（和谁、相似多少）」，**不拦**——合并/改写/保留/放弃，自己决定
- **≥90%**：**拒绝写入**，三选一：revise 改写那条 / merge 合并过去 / 换新角度

拦的是内容重复（余弦），不是标签复用（tag 相同 ≠ 内容重复）。

## 谱（spectrum）——不进账

谱只干两件事：① 读世界时贴「预期新奇 X%，会归到哪个分支」；② trace 一条记忆的谱位置。
账只在落记忆时记。实现口径：

- 分支 = 金字塔成员（L1 + L3）：L1 按主标签、L3 按归属聚合；L2 是草稿本不进分布。
- 每个分支中心向量 = 分支内所有记忆的平均；分支名直接可读。
- **预期新奇 = 投影残差**：1 − 新内容与最近分支中心的余弦。0 = 正好落在某分支中心，1 = 全新方向。
  残差 > 0.5 = 判为新方向。不随深耕某分支而衰减。
- **有效秩 erank** = 分支占比的熵指数：全挤在 2 个分支 = 僵化（erank 小），均匀铺开 = 丰富。
- 向量总数 < 3（spectrum_min_vecs）时谱无意义，compute 返回空，相关标注降级。
